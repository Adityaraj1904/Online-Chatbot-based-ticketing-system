# 🎟️ Online Chatbot‑Based Ticketing System (SIH Project)

A smart, conversational **Museum ticket booking platform** that lets users search, book, and manage tickets through an **AI‑powered chatbot** and a modern web interface. Built for **Smart India Hackathon (SIH)** to showcase a practical, user‑friendly solution for high‑traffic booking systems.

---

## ✨ Key Features

- 🗓️ **Slot‑based bookings**: Choose date/time slots (per‑hour or session‑based) with live capacity.
- 🎟️ **Ticket types**: Adult, Student, Child, Senior, Group, and Special Events.
- 🧭 **Exhibition discovery**: Explore current/coming exhibits, galleries, and highlights.
- 👥 **Visitor flow**: Headcount, multi‑ticket cart, promo codes (planned).
- 🤖 **Chatbot guide**: Conversational flow for searching exhibitions, recommending time slots, and completing checkout.
- 🔐 **Auth**: Sign up / login; planned OTP / email verification.
- 💳 **Payments**: Gateway‑ready (sandbox first), receipts and QR codes (planned).
- 📩 **E‑ticket**: Downloadable ticket with QR for entry scan (planned).
- 📱 **Responsive UI**: Works across desktop and mobile.

## 🧭 Typical Booking Flow

1. **Discover**: User asks “What can I see this weekend?” → chatbot shows exhibitions and ticket options.  
2. **Select**: Pick museum, date, time slot, and ticket types (e.g., 2 Adults, 1 Student).  
3. **Auth**: Login/Signup.  
4. **Pay**: Redirect to payment gateway; on success, generate order + e‑ticket (QR).  
5. **Manage**: View bookings, download receipt/e‑ticket; request reschedule/cancel (policies apply).
